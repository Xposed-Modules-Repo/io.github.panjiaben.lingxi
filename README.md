# 灵犀 · Lingxi

> **让 AI 真的看懂你在跟谁聊、聊到哪了**

灵犀不是"复制一段话去问大模型"。它常驻在你的聊天页里：进聊天就自动读最近的往来，
语音会真听懂、图片会真看懂，然后给你三条能直接发出去的候选。

## 核心能力

- **真读上下文** —— 进聊天自动读最近 10 条，不用你复制粘贴
- **真听懂语音** —— 语音消息直接转文字理解
- **真看懂图片** —— 收到的图能读出内容再生成回复（需要模型支持看图）
- **学你说话** —— 从你自己发过的话里提炼语气，不是通用模板
- **好友级人设** —— 每个联系人单独设关系、称呼、玩笑尺度
- **三条候选** —— 稳妥 / 幽默 / 推进，点一下直接发送
- **自动 / 半自动** —— 打游戏、开会、睡觉时也能接得住话
- **企业微信截图不再黑屏** —— 可在设置里开关
- **微信版本一键降级** —— App 内直接下载安装，聊天记录不丢（告别手动卸载重装）

## 使用要求

- **Android 9 及以上**
- **需要 root**（Magisk / KernelSU / APatch 均可）
- **需要 LSPosed**（Xposed 模块的运行环境）
- 作用域勾选你实际要用的 App：微信 / 企业微信 / QQ / 陌陌

> 只是普通聊天用户、没有 root 的话，这个模块用不了 —— 这是 Xposed 类模块的硬门槛，提前说清楚，省得白装。

## 怎么开始

1. **装模块** —— 装上 APK，LSPosed 里启用「灵犀」，重启手机
2. **勾作用域** —— LSPosed → 灵犀 → 勾上要用的 App，重启那个 App
3. **进聊天** —— 底部浮出卡片，点「刷新」出三条候选

第一次打开可以**免费试用 1 小时**，不用注册。

## 已知边界（如实写）
